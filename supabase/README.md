# supabase/

Laci penyimpanan **hasil template final** — tempat menaruh template yang sudah lolos eksperimen dan siap dipakai.

## Isi

| Folder | Untuk apa |
|--------|-----------|
| `functions/template-library/` | Fungsi Supabase: pustaka template final |
| `functions/wedding-guestbook/` | Fungsi Supabase: buku tamu undangan |
| `migrations/` | Perubahan struktur database (urut waktu) |

## Aturan

- Hanya template/fungsi yang **sudah final** (lolos test di lokal) yang masuk sini.
- Eksperimen tetap dikerjakan di area lokal, bukan di laci ini.
- Setiap folder punya penanda `.gitkeep` agar strukturnya tetap tercatat meski masih kosong.
